# --- terminal emulation ----------------------------------------------------
# Added 2026-08-10 with the escape-sequence census ([SPEC:CXC-TERM] ·
# [CXC-TERM-CENSUS]), which is the first code in the tree to import it. Pure
# Python, no dependencies of its own. VERIFIED on THIS interpreter (macOS,
# CPython 3.13.2): imports, and a HistoryScreen + Stream were driven with the
# real captured byte streams — the pin is an observed-good one, not a latest
# release number ([CXC-TERM-EMULATOR]).
#
# SCOPE NOTE + THREE MEASURED HAZARDS, so nobody adopts it believing it is
# complete (the census drove the library to find these — they are not readable
# off its docs):
#   1. It RAISES. `\x1b[?6n` (DECDSR) -> TypeError: report_device_status() got
#      an unexpected keyword argument 'private'. Claude Code emits it. An
#      unguarded stream.feed() therefore CRASHES on real input.
#   2. It MISAPPLIES private-marker sequences. Only `?` is recognized for h/l;
#      `CSI < u` (kitty keyboard pop) dispatches to restore_cursor and MOVES THE
#      CURSOR, and `OSC 133;A` is parsed as OSC **1** (set icon name) because
#      pyte reads only the first character of the OSC code.
#   3. It DROPS silently — including `?1049h`/`?2004h`/mouse modes, which it
#      stores in `screen.mode` and then implements NO behaviour for. pyte 0.8.2
#      has NO alternate screen buffer.
# All three are why [CXC-TERM-SEQTABLE]'s pre-scan sits UPSTREAM of the emulator.
pyte==0.8.2
