Hello World — end-user licence agreement (conformance fixture hello-world-eula)

1.	Scope. This text exists so that a host can prove its consent screen shows a declared
	EULA exactly and in full, before the accept control ([CXC-PC-V02-EULA-HOST-OBLIGATION]).
2.	Grant. The fixture grants nothing and asks nothing; it greets on the bus and answers
	each ping with a pong, exactly as hello-world v1 does.
3.	Fidelity. A screen that truncates this text, summarises it, turns its line feeds into
	spaces or shows a different text of the same length does not show this EULA.
4.	Characters. The tab at the start of each clause, the em dash in the title and the
	café in this sentence must survive the screen unchanged.
5.	Length. The text is longer than one thousand characters, so that a screen showing
	only the first thousand and a link is caught: the helper eula_text_shown returns
	False for it, and True only when this whole text appears as one contiguous string.
6.	No warranty. The fixture is provided as is, for tests only.
