Authoring Headless Widgets as Logic Nodes

A headless widget is a logic node in the same graph as namespace hubs and visual widgets — inputs it subscribes, outputs it publishes, a schedule, and its logic written in the expression DSL. Wire it like any node; author it in the Inspector; deploy the set as a roster to bus storage. The graph stays a pure projection of the .compose.yaml.
