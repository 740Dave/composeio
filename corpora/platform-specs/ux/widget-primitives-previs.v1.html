Default Widget Primitives

Six missing UI primitives, built as ComposeUX composites — reusable components you fork, not code widgets that lock the look. This is the reference aesthetic and the build spec: each is a stack of existing primitives wired with bindings + the expression DSL. Restyle by cloning the .compose.yaml.

Every primitive is a component — the default is a starting point, not a lock. Fork the composition, keep the tokens above for a consistent family, restyle the rest. · Sonnet: progress_bar · numpad · keyboard · switch  |  Opus: slider · dropdown  |  Fable: not needed.
